# Skylar Pietraszewski — Employment Package

This folder is the working source for a truthful, consistent job-search package.

## Start here

1. Replace every `[PLACEHOLDER]` in `resume.md`, `linkedin-profile.md`, and `github-profile-README.md`.
2. Review dates, education wording, contact details, and location.
3. Export `resume.md` to PDF after review.
4. Create a GitHub profile repository named exactly after the GitHub username and use `github-profile-README.md` as its `README.md`.
5. Publish the `portfolio-site/` folder using GitHub Pages or another static host.
6. Use `application-kit.md` to tailor each application; never send the generic draft unchanged.
7. Track every application in `application-tracker.csv`.

## Contents

- `resume.md` — one-page source resume
- `nova-case-study.md` — flagship project narrative
- `nova-project-README.md` — GitHub-facing project presentation
- `linkedin-profile.md` — paste-ready LinkedIn copy
- `github-profile-README.md` — profile repository copy
- `portfolio-site/` — responsive static site
- `target-roles.md` — role priorities, search terms, and fit boundaries
- `application-kit.md` — cover letter, outreach, and interview stories
- `application-tracker.csv` — application tracking template
- `truth-boundaries.md` — claims ledger for keeping all materials accurate

## Publishing order

Resume → GitHub profile → Nova presentation repository → portfolio site → LinkedIn → reviewed applications.

Account changes and applications require Skylar's review. Availability, work authorization, compensation, background questions, relocation, and start date must never be guessed.
